# Apex Descarga Desktop 0.2.1 UI Pro — Beta corregida

Esta versión corrige la interfaz de Windows 11 tras pruebas del creador. **No es una versión firmada para producción.**

### Correcciones
- Eliminados los solapamientos de tarjetas, controles y bloques de Ajustes, Inicio, Cola y Biblioteca.
- Pantalla Acerca de reorganizada con sección clara de soporte.
- «Escribir al soporte» abre la app de correo predeterminada. Si no hay una configurada, copia el correo y muestra instrucciones.
- Enlace editable del diseño [Figma UI Pro 0.2.1](https://www.figma.com/design/3bk5fsYXv0S8IVox5emltv).
- Motor, cola, biblioteca, ajustes e historial conservados respecto de 0.2.

**Contacto:** angelrlpz030207@gmail.com.

### Cómo probar
Descargar `ApexDescargaDesktop.exe` desde Assets y comprobar el archivo .sha256. Revisar con Microsoft Defender. No es un ejecutable firmado por Authenticode; FFmpeg/Deno se instalan por separado cuando los requiera el origen.

La compilación automática de GitHub incluye pruebas del motor y autocomprobación del EXE; la versión requiere comprobación visual en Windows 11 real.
