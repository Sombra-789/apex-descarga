# Apex Descarga Desktop 0.2 UI Pro — Windows 11 Beta

**Aplicación independiente de Brave** con estética Apex Visual Studio: cinco pantallas (Inicio, Descargas, Biblioteca, Ajustes, Acerca de), tarjetas modernas, miniaturas, progreso, filtros, paletas HEX y logotipo opcional.

### Descarga

En **Assets**, descarga `ApexDescargaDesktop.exe` y `ApexDescargaDesktop.exe.sha256`. El EXE incluye Python y yt-dlp y **no requiere Python instalado**, pero FFmpeg y Deno deben instalarse por separado cuando sean necesarios para ciertos formatos/sitios.

**IMPORTANTE: Beta sin certificado Authenticode, no es instalador estable de producción.** Comprueba el origen, analiza con Microsoft Defender y verifica el SHA-256. No desactives SmartScreen o Defender ante alertas inesperadas. No se proporciona ejecutable para macOS/Linux.

### Mejoras frente a 0.1

- Layout Windows UI Pro con sidebar de cinco secciones y vista previa multimedia.
- Cola con tarjetas y acciones rápidas; búsqueda y filtros de biblioteca; modo compacto y ajuste HEX.
- Conserva la cola secuencial, yt-dlp/FFmpeg, historial y preferencias en `%LOCALAPPDATA%\ApexDescargaDesktop\`.
- Sin inicio de sesión ni telemetría propia. Revisa la política de privacidad del repositorio.
